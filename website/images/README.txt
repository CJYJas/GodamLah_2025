INSTRUCTIONS FOR SCREENSHOT IMAGES
===================================

Please place your screenshot images in this folder with the following filenames:

1. easy-mode-screenshot.png (or .jpg)
   - This will be displayed in the "Easy Mode" iPhone mockup

2. normal-mode-screenshot.png (or .jpg)
   - This will be displayed in the "Normal Mode" iPhone mockup

3. rural-mode-screenshot.png (or .jpg)
   - This will be displayed in the "Rural Mode" iPhone mockup

Supported formats: PNG, JPG, JPEG

The images will automatically scale to fit the iPhone mockup frames.
easymode.jpeg.jpeg
ruralmode.jpeg.jpeg
normalmode.jpeg.png
